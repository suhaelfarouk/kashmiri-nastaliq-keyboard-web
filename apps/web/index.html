How to type

WYSIWYG editing: what you type is the finished document — format with the toolbar above the editor, and Preview and Print always match it exactly. Open and download .docx files (legacy .doc is not supported — re-save as .docx in Word first); drafts autosave in this browser. QWERTY layout: keys follow the same left-to-right order as a normal English keyboard. Phonetic mode: type Latin sequences such as sh → ش, kh → خ, chh → چھ, aa → آ, t' → ٹ. Vowel controls: ~ → ٟ, ^ → ٖ, : → ٗ. Direct QWERTY uses one key per character.

Layers: Shift gives alternate letters, Alt gives aspirated digraphs, vowel sequences and combining marks, and Alt+Shift gives loan-word consonants, precomposed vowels and punctuation. Hold the physical keys, or pick a layer with the buttons above the keyboard. Show both layers prints the alternate character in red next to the base one. Font and Size change the whole document; both are saved with your draft. Downloads name that face in the .docx file but do not embed the font file, so another computer uses it only if it is installed there.
